ApexPlanet Internship - Task 3 Solution (10-Question Variant)
=============================================================

Description:
This project fulfills the requirements for Task 3 (Advanced Styling and JavaScript). It has been upgraded to feature a dynamic 10-question multiple-choice quiz and a personalized header.

Features Implemented:
1. Responsive Design Using Media Queries: Adapts beautifully to mobile and desktop screens.
2. Interactive 10-Question Quiz: 
   - Dynamically loads 10 Web Development questions using JavaScript arrays.
   - Tracks user score out of 10.
   - Provides immediate visual feedback (Correct/Incorrect) and allows restarting the quiz at the end.
3. Fetch API Data: Pulls real-time advice from a public JSON API asynchronously.

How to Run:
1. Extract this ZIP file.
2. Open "index.html" in any modern browser.
